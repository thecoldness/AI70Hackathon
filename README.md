# Trace — The art of learning

为 Dartmouth AI at 70「What Must Remain Human?」制作的可交互网页 demo。核心是记录参考、亲自练习、比较与反思，并把过程呈现为可探索的学习路径。

## 启动

```sh
npm install
npm run dev
```

打开终端显示的本地地址。构建检查：`npm run build`。不需要 API key、后端或浏览器扩展。

## 一条完整的演示路线

1. 在首页点击 **Start a learning journey**，选择 Van Gogh，保留或修改自己的学习问题，点击 **Start my journey**。
2. 在模拟 Pinterest 页面打开 **Wheat Field with Cypresses**，点击右下角 **Record this reference**。关闭详情，再记录 **Café Terrace at Night**。
3. 切到左侧 **Instagram**，打开并记录 **Irises**。平台来源、顺序和图片都保留在本次学习记录里。
4. 点击 **references connected →** 可以立即查看个人路径；或进入左侧 **My practice**。
5. 在练习画布上绘画、导入自己的 PNG/JPEG/WebP，或点击 **Preview sample study** 使用清楚标注的演示素材。
6. 点击 **Add this study to my path**。选择真正帮助了这次练习的参考，写一句自己的观察，再确认保存。练习和反思都会进入图谱。
7. 点击自己练习的节点，然后 **Compare & reflect**。比较原作、自己的练习和示例临摹；可以切换示例、给感悟点赞、保存自己的文字、打开关联教学提纲。
8. 关闭对比，点击 **Find a path from here**。在右侧选择 Mina 的成果，或在图谱上点相应练习，回放从共同参考出发的学习过程。支持暂停、逐步查看和重新播放。
9. 切到 **Community atlas**，探索 Van Gogh、Monet、Hokusai 三个群组。可拖动画布、缩放、点击节点，或选择热门及较少人走过的路径。

顶部摄像机图标打开 **Walkthrough** 控件，可快速跳转六个场景。回转箭头重置 demo；下载图标导出当前学习记录。`⌘/Ctrl + 1` 打开图谱，`⌘/Ctrl + 2` 打开画布，`Esc` 关闭当前对话框。对话框支持键盘焦点循环。

## 2 分 20 秒视频安排

| 时间 | 画面与讲述 |
| --- | --- |
| 0:00–0:15 | 主题：成果变得容易获得，理解仍需要人在实践中形成。 |
| 0:15–0:40 | 开始学习；在两个模拟平台挑选、记录参考。 |
| 0:40–1:00 | 展示个人路径，进入练习并确认保存；有真实绘画录像时可插入几秒。 |
| 1:00–1:35 | 原作、练习和同伴尝试对比；阅读并回应一条感悟。 |
| 1:35–2:05 | 缩远到共同图谱，选择起点和另一成果，回放学习路径。 |
| 2:05–2:20 | 说明系统承担记录、连接、反馈入口；人保留选择、观察、动手和反思。 |

推荐使用 Mac 上已有的 OBS 或 QuickTime 录屏，iMovie 剪辑和配音。保留页面中的演示标记；提交视频控制在 2:30 内。录制前点击重置、关闭多余标签页、完成一次彩排。建议使用横屏，浏览器缩放保持 100%。

## 演示边界

- Pinterest 与 Instagram 页面是本地模拟页面，没有连接或爬取真实平台。
- 没有连接实际 AI 模型；记录、关联和页面效果由 demo 的确定逻辑驱动。
- 社区人物、文字、路径、点赞和热度是示例数据。路径回放使用明确记录的示例序列，不把图谱最短路径伪装成人的学习经历。
- 练习示例复用公有领域原作并施加 CSS 视觉处理，仅用于说明交互，不是人类学习成果或能力提升的证据。可替换为团队实际绘制并同意展示的作品。
- 图谱中的同一艺术品与用户的选图记录分开表示：来源、时间属于具体的记录事件。
- 只在主动开始后展示记录按钮。暂停后不接受记录；保存练习需要确认。数据保存在当前浏览器的 localStorage；私有笔记不会发送到服务器。
- 当前 demo 保留一轮练习，可以替换该练习；完整的多轮历史、真实账户及多人同步不在本版范围内。
- 图片导入限制为 3 MB。存储空间不足时会提示导出记录，当前页面仍可使用。重置会清空这个 demo 在当前浏览器内的学习记录与互动。
- 参考原作来自 Wikimedia Commons，来源及公有领域标记保存在 [public/art/credits.json](public/art/credits.json)。

## 代码位置

- `src/App.tsx`：学习会话、模拟平台、练习、对比、反思及演示场景。
- `src/Atlas.tsx`：D3 力布局、SVG 图片节点、路径、缩放和平移。
- `src/data.ts`：作品、节点、示例人物、感悟与明确的学习序列。
- `src/styles.css`：界面、响应布局、动效与减少动效设置。

技术栈：React、TypeScript、Vite、D3-force、Lucide 图标。网页为静态应用，在线发布也不上传浏览器内的个人记录。
